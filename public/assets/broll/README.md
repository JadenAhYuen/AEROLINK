# B-roll folder

Put your landscape drone clips in this folder. The viewer discovers them
automatically and crossfades from one clip to the next while it is waiting for
a live feed.

- Use MP4 (H.264) or WebM clips.
- Export in 1920x1080 or 3840x2160, 16:9, with no audio required.
- Keep file names simple: lowercase letters, numbers, and hyphens.
- No playlist or restart is required; reload the viewer after adding a clip.
